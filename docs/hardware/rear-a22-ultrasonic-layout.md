# A22 四探头后向测距安装草案

状态：2026-10-28 初版，依据 A22-V1.0 单探头规格书和现有底盘 520 × 350 mm 外廓；2026-10-29 补入规格书核对过的线序、型号分型、Modbus 寄存器与供电/接地要求，并确认订单是 **A22×4 + DYP-E08、RS485 主输出**，据此改写接口章节。仍缺 E08 的四通道寄存器映射、车尾实照和折叠腰部扫掠尺寸。以下为支架定位尺寸，不是开孔图。

## 目的与边界

前置 C1 雷达的后方长期被车体、后续电池和电脑遮挡；`/scan_mapping` 后向遮挡区已被屏蔽。四只 A22 探头用于补足车尾近场的实时障碍感知，首先提供后退停车约束。单束超声只能给出锥形范围内的最近距离，不能证明锥外无障碍、不能替代后向二维地图，也不能单凭历史走过轨迹开放自动倒车。实车自动倒车仍需另行验收。

## 安装基准与建议位置

- 底盘坐标：`base_footprint` 为地面几何中心；+X 朝车头、+Y 朝左、+Z 朝上。现有实测底盘外沿约 X=±260 mm、Y=±175 mm；Nav2 当前规划轮廓为 600 × 430 mm，含余量，但最终安装后须重新量外廓。
- 四只探头的发射面尽量与车尾外缘齐平，约 X=-260 mm；安装中心离地建议 140 mm，暂容许 130–150 mm。建议固定在**底盘刚性后横梁/独立后保险杠**，不固定在折叠腰部、活动电脑托架或薄金属振动片上。电子主机放在受保护的内侧，探头前方保持无遮挡。
- 从车尾看，四个探头按 `左外、左内、右内、右外` 排列。下表中的偏角是相对正后方，朝各自外侧偏转；角度和位置是待实测调整的初值。

| 探头 | 位置 `(x,y,z)` mm | 发射方向（底盘 yaw） | 主要覆盖 |
| --- | --- | --- | --- |
| 左外 | `(-260,+105,140)` | 后方偏左 10°（约 170°） | 左后角、左侧后缘 |
| 左内 | `(-260,+50,140)` | 正后（180°） | 后方偏左 |
| 右内 | `(-260,-50,140)` | 正后（180°） | 后方偏右 |
| 右外 | `(-260,-105,140)` | 后方偏右 10°（约 -170°） | 右后角、右侧后缘 |

```text
俯视，车头在上；尺寸单位 mm
          +X 车头
       ┌──────────────────────┐   宽 350
       │ 电池/电脑及折叠腰部  │
       │                      │
       └─╲──●──●────●──●──╱─┘   X≈-260，车尾
         左外 左内  右内 右外
         Y+105 +50   -50  -105
        外侧探头各向外转约 10°
```

初始使用规格书的最窄角度等级约 30°（全角），以降低相互串扰和地面/车体回波。按理想锥形几何估算，在车尾后 0.2–0.3 m 处四束横向范围大致重叠并覆盖 350 mm 车宽；**规格书的角度来自特定圆柱/纸箱测试，近场并非硬边界，不能把这项几何估算当作可靠覆盖证明**。若实际版本不能设角度，需按实际声束重定位置和停止距离。

## 规格书约束（单只 A22-V1.0）

- 供电 3.3–12 V DC，平均工作电流 ≤9–10 mA、峰值电流 ≤150 mA；四只探头理论峰值合计可达 600 mA，尚未计一拖四主机。预留独立稳定的 5 V、至少 1 A 供电能力，最终按主机铭牌核定；不要直接借用电机驱动板的 3.3 V 针脚。
- 标称盲区 ≤1 cm，平面目标量程 1–300 cm；可选量程等级约 0.5/1.5/2.5/3.5 m。角度等级约 30/40/50/60°。特殊码 `0xFFFE` 为同频干扰、`0xFFFD` 为无目标，应视为无可靠近场读数，不能解释成“安全空地”。
- 单探头外形图：前脸高度约 47 mm、两固定孔中心距 40 mm，建议安装长圆孔 31.2 × 16.2 mm、板厚 1–4 mm，壳体向后约 22.5 mm；随附线约 330 mm。外形与开孔必须以实际收到的探头/支架核对，再决定是否在金属件上加工。
- 推荐探头发射面露出保险杠，周围不要形成深孔或突出边框；探头平面与后方目标大致平行。避开轮胎、排线、折叠腰部全行程和金属共振件。低位安装可能读到地面，也可能漏掉高于声束或低矮、细窄、吸声的障碍；用纸箱、细杆、低障碍做近场实测确认。

## 四线定义与电平（2026-10-29 核对规格书第 4、5、16–17 页）

引线颜色固定：**红=1 VCC、黑=2 GND、黄=3 RX/B、白=4 TX/A**。端子为 4 pin 带黑胶卡扣，随附线约 330 mm。插头与插座视图的编号互为镜像，**按颜色接，不要按编号接**。

第 3/4 脚的功能由**型号后缀**决定，出厂固定、互不兼容（第 18 页）：

| 型号 | 输出 | 第 3 脚 RX/B | 第 4 脚 TX/A |
| --- | --- | --- | --- |
| DYP-A22YYUW | UART 自动 | 上电 500 ms 内电平选择（高/悬空=处理值，低=实时值），之后为 Modbus 接收 | 连续输出，周期 100–180 ms |
| DYP-A22YYTW | UART 受控 | 触发输入，下降沿触发一次，周期须 >150 ms | 每次触发输出一帧 |
| DYP-A22YYMW | PWM | 触发输入，周期须 >50 ms | PWM 高电平，S(cm)=T(us)/57.5；无目标约 21 ms |
| DYP-A22YYGDW | 开关量 | 上电电平选择 | 高/低电平，无驱动能力 |
| DYP-A22YYCW | IIC | SCK | SDA（3–10 kΩ 上拉，通讯电平等于 VCC） |
| DYP-A22YY4W | RS485 | B（反相） | A（同相），Modbus RTU，默认 115200 |

**电平风险**：IIC 章节写明“通讯电平等于 VCC”，UART 章节未写；供 5 V 时白线高电平可能是 5 V，而 ESP32-S3 的 IO 不耐 5 V。接线顺序必须先只接红/黑、白线悬空，量出白—黑高电平后再决定直连还是加电平转换。黄线是输入方向，S3 的 3.3 V 高电平满足 TTL VIH，可直连。

UART 自动型四只**不能共一条线**：它自己主动输出，主机止不住，无法错时。共用总线只能走 RS485（地址区分）或 IIC（地址区分），否则一拖四主机必须自己分时轮询。

## 供电与接地

- E08 主接口供电 **5–24 V DC**，可直接接电池 12 V；RS485 输出档自身 ≤9 mA（不含探头）。四只探头由 E08 的 1–4 口供电，整组平均约 40–50 mA、峰值约 600 mA。
- 单只 A22：3.3–12 V、峰值 150 mA、待机 ≤5 µA；输入纹波 ≤50 mVpp、噪声 ≤100 mVpp 是硬指标。
- **最大风险是 E08 与电机驱动共用 12 V 电池母线**：AT8236 的 PWM 与电机换向噪声会直接耦合进来。E08 支路要从电池单独取电（不要从驱动板端子上搭），串自恢复保险丝 + 磁珠/π 滤波（10 µH + 470 µF），入口加 TVS 与反接保护；探头由 E08 就近供电。
- 不要从电机驱动板 3.3 V 针脚取电；不要挂 Jetson USB 口——峰值电流可能触发过流，连带丢掉 `ttyACM1` 底盘链路。
- 降噪等级（A22 的 Modbus `0x021A`）按实际供电设：电机/开关噪声环境 3–4、干净电池供电 1–2。等级越高抑制越强但角度收窄、小目标易丢，改档后须复测覆盖。
- 上电工作时间 ≤650 ms，首条命令前等 ≥700 ms。

## 一拖四主机 DYP-E08（2026-10-29 查厂家产品页与 E08 操作说明）

E08 是 4 路转换模块，把 1–4 只测距模块汇总成一路主输出，支持同时、交叉或轮询工作；**端口 1–4 只能接 UART 通信型超声模块**。所以订单里的四只 A22 是 UART 自动/受控型，不是 RS485 型——“RS485”指 E08 对主机侧的输出接口。

E08 主接口四线（RS485 档，黄白含义**与探头相反**）：

| 引线 | 颜色 | RS485 档 |
| --- | --- | --- |
| 1 | 白 | B（反相） |
| 2 | 黄 | A（同相） |
| 3 | 黑 | GND |
| 4 | 红 | VCC，DC 5–24 V |

## E08 Modbus 寄存器（依据 V2.0 规格书，2026-10-29 核对）

从机地址默认 `0x01`（可设 0x00–0xFE，但 **0x02–0x05 被四只探头占用，不能用**）；主口默认 **9600**。

| 寄存器 | 功能 | 说明 |
| --- | --- | --- |
| `0x0000` | 软件版本 | 只读 |
| `0x0106`–`0x0109` | 接口 1–4 距离 | 从 `0x0106` 起连读 4 个 = 一次取四路 |
| `0x0200` | 从机地址 | 仅 RS485 模式 |
| `0x0201` | 主口波特率 | `0x03`=9600，`0x09`=115200 |
| `0x0202` | 输出模式 | `0x00` 受控（UART 默认）/ `0x01` 自动 |
| `0x0207` | 实时值/处理值 | `0x00` 处理值（默认）/ `0x01` 实时值 |
| `0x0208` | 批量配置四只角度等级 | 一次改完四只 |
| `0x0214` | 批量读四只波特率 | **只读** |
| `0x0215` | 触发超时 | 单位 10ms，默认 `0x14`=200ms |
| `0x0216` | 工作模式 | `0x01` 同时 / `0x02` 交叉 / `0x03` 轮询 |
| `0x021A` | 批量配置四只降噪等级 | |
| `0x021F` | 批量配置四只量程等级 | |

要点：

- **工作模式默认就是 `0x03` 轮询**。这是唯一不让四只探头互收的模式，出厂值已经正确，不要改成 `0x01` 同时。
- 轮询一轮：`49ms + 4×探头响应`，上限 `9ms + 4×超时`；默认 200ms 超时下最坏约 0.8s。连读四路（`0x0106` 起 count=4）响应为 `25ms+探头响应` ～ `25ms+超时`。
- 四只探头的角度/量程/降噪**可批量配置**，不需要像裸探头那样逐只拆下来直连。前文“改参数必须脱离 E08 直连”只适用于单独标定裸探头。
- `0x0214` 只能**读**四只探头的波特率，规格书没有给出写接口波特率的寄存器；合理推断 E08 会自适应各接口波特率。先用 `0x0214` 和 `0x0106` 实测确认，不要急着改波特率。
- `FFFF`=该接口探头无应答、`FFFE`=同频干扰、`FFFD`=无目标；三者都按“无可靠读数”处理。
- 调试工具：`tools/e08_probe.py`（`--info` 打全部配置，默认读四通道，`--watch` 连续观察）。

## 接口与软件接入建议

**单只 A22 的寄存器**（第 11–13 页，改参数时必须脱离 E08、直接接调试器）：只读 `0x0100` 处理值（100–300 ms）、`0x0101` 实时值（15–140 ms）、`0x0102` 温度、`0x010A` 回波时间——**读这几项本身即触发一次测距**。读写 `0x0200` 从机地址、`0x0201` 波特率、`0x0208` 角度等级（1–4 级 = 30/40/50/60°，出厂 4）、`0x021F` 量程等级（1–4 级 = 约 0.5/1.5/2.5/3.5 m，出厂 4）、`0x0209` 距离单位、`0x021A` 降噪等级。`0xFFFE` 为同频干扰、`0xFFFD` 为无目标，两者都按“无可靠读数”处理。四只探头分别挂在 E08 的 1–4 口、不共总线，因此不需要改地址；刷新率由 E08 的轮询周期决定，未实测。

**主机侧**：ESP32-S3 的 console 走 USB-Serial/JTAG（`sdkconfig` 已确认 `CONFIG_ESP_CONSOLE_USB_SERIAL_JTAG=y`），UART0/1/2 全空；GPIO 4–11 已被电机 PWM 与编码器占用；GPIO 19/20 是 USB D-/D+，GPIO 0/3/45/46 是 strapping，均不可用。建议 UART1：TX=GPIO17、RX=GPIO18、DE/RE=GPIO16，配 3.3 V 的 SP3485/MAX3485。

ROS 侧建议每路保留独立时间戳/状态和距离；后退时任一路必要探头过期、干扰、无效或报告近障，就输出零速。近障停车阈值应由实测轮速、四路完整刷新周期、控制延迟、实际地面制动距离及余量计算，再做静态纸箱和移动障碍的有人看护验证。超声测距只增加占用或停止约束，不向二维地图写入“空闲”，也不清除激光发现的障碍。原有车尾盲区与自动倒车关闭状态在验收前保持不变。

## 安装前必须补齐的尺寸

1. 车尾正面和俯视照片，尺子标出实际可用平板宽高、折叠腰部/电脑托架运动扫掠范围、电池和线束位置；确认探头前脸离地 130–150 mm 且背后有 22.5 mm 以上净空。
2. E08 的四通道距离寄存器映射与轮询周期；四只探头的实际型号后缀；E08 端口 1–4 的针序与线长（按实物丝印/颜色核对，不要用主接口的针序套端口）。
3. 最终装配后在 0.15、0.25、0.40、0.60 m 处沿车尾宽度逐点摆放纸箱、细杆和低矮障碍，记录各探头读数、地面/车体误回波、漏检带及停车距离；据此定最终角度和止停阈值。

依据：用户提供的《DYP-RD-产品规格书(DYP-A22-V1.0)-230522-A0.pdf》产品第 1–4、10–12、18–20 页；厂家当前 [A22 产品页](https://www.dypcn.com/dyp-a22-ultrasonic-sensor-avoids-obstacles-product/) 供交叉核对。厂家网页的盲区数值与用户所给 PDF 版本不同，安装与安全阈值以收到的具体型号实测为准。

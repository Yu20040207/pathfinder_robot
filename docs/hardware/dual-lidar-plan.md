# 双雷达方案（feature/dual-lidar）

**分支**：`feature/dual-lidar`
**基线**：`lidar-single-baseline`（tag，commit `8d2e936`）
**基线文档**：[`docs/hardware/lidar-single-baseline.md`](../hardware/lidar-single-baseline.md)
**开始日期**：2026-11-18

---

## 目标

1. **360° 覆盖**：前后两个雷达，各取 260°（遮掉自己后方 ±50°），并集 = 完整 360°
2. **看见低位障碍**：解决当前 75 mm 扫描面看不见 <75 mm 物体的安全隐患
3. **解锁自动倒车**：后方可见后可评估 `allow_reversing`（需灰度验证）

---

## 硬件布局（用户确认）

```
    y=+180 ┌──────────────────────────┐  ← 车体 600 × 360 mm
           │  ▓▓ 窗带（0.11~0.19 m）   │
           │   ┌──────────────────┐   │
           │   │ 电池 / 主控 / 驱动 │   │  ← 兼作光学隔板
    y=0    │ ● │                  │ ● │
           │前雷达             后雷达│
    y=-180 └──────────────────────────┘
        x=−300                      x=+300
```

| 项 | 前雷达 | 后雷达 |
| --- | --- | --- |
| 位置 | `(+0.30, 0, z)` | `(−0.30, 0, z)` |
| **高度** | **同高**（用户决定）| 同高 |
| frame | `laser_front` | `laser_rear` |
| 遮罩 | 后方 ±50°（130°~230°）| 前方 ±50°（−50°~+50°）|
| 有效 | 260° | 260° |

**隔板**：中央设备块 + 顶部薄板，需在扫描面高度（±50 mm）连续不透明，防止两雷达对视。

**窗带**：`0.10~0.18 m` 高（60~80 mm），绕车体连续一圈（侧面两段重合）。

**柱子遮罩**：结构柱若不避开扫描面，用多段遮罩；要求每段 ≤5°。

## 关键技术决策

| # | 决策 | 理由 |
| --- | --- | --- |
| 1 | **不用 merge 节点合并 scan** | 两雷达相位差 0~100 ms，旋转时 100 ms × 0.55 rad/s = 3.15°，2 m 处偏 110 mm → **重影** |
| 2 | **Cartographer 用 `num_laser_scans = 2`** | 原生支持多路，各按自身时间戳插入，不拖影 |
| 3 | **代价地图双 source，不合并** | `obstacle_layer` 原生支持 |
| 4 | **遮蔽值用 `+inf`，不用 NaN** | NaN 会让 Cartographer 产出垃圾位姿（单雷达已踩过）|
| 5 | **建图只用前雷达（先做 A 方案）** | 两个传感器的系统误差不一致会造双墙；安装偏航误差 >0.5° 时 5 m 处偏 44 mm |
| 6 | 后雷达**先只做避障** | 只需覆盖，不需精度 |

> **决策 5 待实测**：若共面/同向标定误差 <0.3°，可启用双雷达建图。

## 风险

| # | 风险 | 缓解 |
| --- | --- | --- |
| 1 | 双雷达建图出现双墙 | 先只让前雷达建图（决策 5）|
| 2 | 两雷达互相干扰（幽灵点）| 隔板 + 高度错开（如部可用）+ 内部遮光 |
| 3 | 后轮挡住后雷达 | 实测覆盖角，必要时外移 |
| 4 | 窗带自击 | `min_range` 提到 0.20 + 实测验证 |
| 5 | 雷达外露撞墙 | 下沉式安装 + 保护条 |

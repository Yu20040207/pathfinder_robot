# 后向 A22 超声：交接资料（硬件已装好，软件未开始）

状态：2026-10-31。四只 A22 探头 + DYP-E08 主机已接好并**在实机上读通**；
ROS 侧尚未写任何代码。本文档供接手者一次性掌握全部已验证事实与边界。

## 1. 硬件拓扑

```
A22 探头 ×4 ──(各 4 线, UART 115200)── E08 端口 1~4
E08 主口 (RS485, 白=B 黄=A 黑=GND 红=5~24V)
   └── USB 转 485 (CH340) ── Jetson USB ── Python/ROS 节点
```

- **路线 A**：数据直接进 Jetson，**不改 ESP32 固件**。理由见第 6 节。
- E08 供电 5~24 V，**必须独立一路 12 V**（加自恢复保险 + 磁珠/π 滤波），
  不要用 USB 转换器的 5 V 脚供电（四只探头峰值约 600 mA，会触发 USB 过流）。
- 主口线序**与探头相反**：E08 白=B、黄=A；A22 探头 黄=RX/B、白=TX/A。

## 3. E08 寄存器表（RS485 模式）

| 寄存器 | 功能 | 说明 |
| --- | --- | --- |
| `0x0000` | 软件版本 | 只读 |
| `0x0106`–`0x0109` | 接口 1–4 距离 | 单位 mm；从 `0x0106` 起 count=4 一次取四路 |
| `0x0200` | 从机地址 | 默认 `0x01`，**`0x02`–`0x05` 被四只探头占用，禁止使用** |
| `0x0201` | 主口波特率 | `0x03`=9600，`0x09`=115200 |
| `0x0202` | 输出模式 | **RS485 模式不应答** |
| `0x0207` | 实时值/处理值 | **RS485 模式不应答** |
| `0x0208` | 批量配置角度等级 | 读 1 个返回 4 个；1–4 = 30/40/50/60° |
| `0x0214` | 批量读接口波特率 | 只读，读 1 返回 4；`0x09`=115200 |
| `0x0215` | 触发超时 | 单位 10 ms，默认 0x14 = 200 ms |
| `0x0216` | 工作模式 | **RS485 模式不应答** |
| `0x021A` | 批量配置降噪等级 | 读 1 返回 4；1–5 |
| `0x021F` | 批量配置量程等级 | 读 1 返回 4；1–4 = 50/150/250/350 cm |

**批量寄存器是"读 1 个、返回 4 个"**，按 count=4 读会得到错误结果（曾因此误判四只探头全部无响应）。

## 4. 协议要点

- 功能码：读 `0x03`、写 `0x06`；CRC-16/MODBUS，**低字节在前**。
- 读四路：`01 03 01 06 00 04 A5 F4` → 回 `01 03 08 <D1> <D2> <D3> <D4> <CRC>`
- 读单路：`01 03 01 06 00 01 65 F7`（`0x0107`/`0x0108`/`0x0109` 同理）
- 读版本：`01 03 00 00 00 01 84 0A`
- 异常值：`0xFFFF` 该接口探头无应答、`0xFFFE` 同频干扰、`0xFFFD` 无目标。
  **三者都必须按"无可靠读数"处理，不能当 0，也不能当"空地"。**
- 读距离寄存器本身即触发测距，没有额外触发线。

## 6. 集成设计约束（重要）

- **不要走 ESP32 固件**：`S2` 遥测帧是固定 14 字段，`base_protocol.py` 严格校验长度，
  加四路距离要改固件 + 改协议 + 改测试，收益不成比例。走 Jetson 侧串口节点。
- 建议新增 `fwr_bringup` 节点，发布 4 路 `sensor_msgs/Range`：
  `frame_id` 建议 `ultrasonic_rear_left_out` / `left_in` / `right_in` / `right_out`。
- **必须处理设备断连**：按 by-id 打开，失败/异常时重试重开；
  `ttyUSB*` 编号会随插拔变化（实测 `ttyUSB0`/`ttyUSB1` 互换过），不要写死编号。
- 时间戳用接收时刻，并保留每路的"最后一帧年龄"；任一路过期即视为不可信。
- 融合原则：超声**只增加占用/停止约束**，不向二维地图写"空地"，
  也不清除激光已发现的障碍。
- **不得因为接入超声而开放自动倒车**：车尾盲区是结构性限制，
  自动倒车许可的解除需要单独验收。

  已 `systemctl mask brltty-udev.service`；**换机器时要重新处理**。
- 仓库内所有串口引用均使用 `/dev/serial/by-id/`，继续沿用。

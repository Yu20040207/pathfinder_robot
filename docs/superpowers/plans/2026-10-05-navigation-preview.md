# 第二阶段首步：离线路径规划预览

日期：2026-10-05

## 目标

在不接通底盘电机、不依赖故障中的 HP60C 的条件下，用 ROS 2 标准 `OccupancyGrid`、`PoseWithCovarianceStamped` 和 `PoseStamped` 输入，计算并发布 `nav_msgs/Path`。这是路径规划预览，供地图和目标点接口验收；后续以 Nav2 取代规划器并接入定位、里程计和速度控制。

## 边界

- 只发布 `/robot/navigation/planned_path`，不发布 `/cmd_vel`，不连接串口或电机。
- 地图未知单元按障碍处理；障碍按可配置半径膨胀。A* 八邻域搜索禁止斜向穿过障碍角。
- 地图与起终点必须属于同一坐标系；起点/终点超界或被阻挡、无路径时不发布新路径，并输出错误。
- 起点来自 `/amcl_pose`，目标来自 `/goal_pose`，地图来自 `/map`。目前本机未安装 Nav2，也没有二代底盘几何参数或里程计；不声称机器人已经可以自主行驶。

## 实施与验证

1. 先写纯 Python 测试：直达、障碍绕行、膨胀、未知区域、旋转地图、角点和无解。
2. 实现独立 `fwr_navigation` 包中的 A* 核心与 ROS 2 适配节点。
3. 构建 ROS 2 包，跑全部测试，并用合成地图/位姿/目标完成一次 ROS 2 话题级验收。
4. 将启动命令、接口和硬件待定项写入 README。二代底盘控制协议、轮径、轮距、编码器/IMU 与急停方式确认后再设计运动执行。

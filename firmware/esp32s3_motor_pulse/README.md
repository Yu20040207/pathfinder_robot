## 编码器测试预留（电平转换板到货后再烧录并接线）

D157B 的 E1A/E1B/E2A/E2B 实测有 4.9 V 高电平，**不能直接接 ESP32-S3 GPIO**。用户提供的商品图为一块四路 HV/LV 双向转换板（看起来是四路 MOSFET 加上拉电阻结构，商家标称最高稳定通信速率 28800 bps）；最终接线前以收到的实物丝印和万用表测量复核。HV 接 D157B 5V，LV 接 ESP32-S3 3V3，GND 与两板公共地连接；四路高压侧接编码器输出，配对的低压侧接 ESP32-S3 输入：

| D157B 信号 | 转换板通道 | ESP32-S3 输入 |
| --- | --- | --- |
| E1A | HV1→LV1 | GPIO8 |
| E1B | HV2→LV2 | GPIO9 |
| E2A | HV3→LV3 | GPIO10 |
| E2B | HV4→LV4 | GPIO11 |

通电时先不接四根 LV 输出到 ESP32，用万用表测转换板 LV 侧高电平不超过 3.3 V、低电平接近 0 V；确认后断电再接 GPIO。不要将 D157B 的 5V 接到 ESP32 的 3V3，也不要用转换板给电机供电。布线短、远离电机动力线。该类 MOSFET 转换板原本常用于 I²C 等信号；商家标称的 28800 bps 不能证明它在本机编码器线束下不会丢边沿。先手转、再悬空低速、最后在悬空最高测试转速检查计数与 skipped，若出现明显漏计或噪声，应换适合编码器脉冲的单向缓冲方案。

固件用 A/B 两相的每次有效跳变计数（4 倍频）；串口输入 `r` 显示 A/B 累积计数和跳变异常数，输入 `z` 清零。短脉冲后也会打印计数。正负号需按实际轮子安装方向标定。此阶段只验证脉冲和方向，尚未根据实际减速比、编码器 PPR 与轮径标定 RPM/里程计；不要把这些原始计数当作准确位移。

烧录时 D157B 电源断开、开关关闭；运行前车轮悬空、12 V 输入极性经过万用表核对，并可立即切断电源。ESP32-S3 USB 单独供电、两板共地。这个固件只做短时空载验收，没有编码器闭环和独立硬件急停，不能驱动车体在地面行走。

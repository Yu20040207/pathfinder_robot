# ESP32-S3 悬空轮速闭环验收

此固件用于 D157B AT8236 驱动板与两个编码器驱动轮的悬空调试。旧的 `esp32s3_motor_pulse` 固件保留用于回退。60 mm/s 的前进和后退悬空闭环测试已通过；仍需下地负载标定，不接 Nav2。

## 已标定的接口

- GPIO4/5：左电机 AIN1/AIN2，AIN1 为前进。
- GPIO6/7：右电机 BIN1/BIN2，BIN2 为前进。
- GPIO8/9：左编码器 A/B；GPIO10/11：右编码器 A/B，经 3.3 V 电平转换接入。
- 前进时原始编码器左负右正，控制器内部统一转换为前进正速度。
- 初始周长 210 mm、每圈 1468 个 4 倍频计数；轮距 263 mm 在上位机里程计中使用。

## 控制和保护

独立 FreeRTOS 控制任务每 20 ms 采样编码器并更新 PWM。串口处理和日志不会主动阻塞该任务。轮速采用低通滤波、前馈加 PI；目标轮速限制为 ±100 mm/s，加速度限制 150 mm/s²，PWM 限制 50%。静止起步时最多给一次 200 ms、50% PWM 起转脉冲；编码器检测到轮速后提前退出。微小反向读数不再跳过起转脉冲。正常控制时 PWM 上升率限制 1/s、下降率限制 0.2/s；停机与故障直接清零。正反转切换先降至零，等待低速后再换向。

有效 `v` 命令超过 300 ms 未刷新时，关闭两路电机输出；`x` 和零速度命令在下一控制周期关闭输出。这里“停止”表示 PWM 清零、驱动输入低，车轮可能因惯性滑行，并不代表机械刹停。上电不运动。故障保持锁定，需要停止状态下显式 `c` 清除或重启后才能重新运行。

故障码：1 无脉冲（连续 `v` 轮速控制在 PWM≥30% 后约 0.45 s；诊断模式另有各自时限）；2 转向反馈反向超过约 0.2 s；3 测得轮速超过 300 mm/s 持续约 0.1 s；4 单周期超过 8 次无效编码器跳变；5 控制周期异常（运动时周期大于 100 ms）；6 跟踪偏差。这些阈值是初始值，仍需带载实测。软件保护不替代电源开关/独立硬件急停，也不包含电流、温度检测；控制任务自身停滞或 MCU 硬件故障仍需硬件切断电机供电。

## 串口协议

115200、8N1、USB Serial/JTAG。新固件先发送 `?`，必须读到 `BASE_CONTROL_V2` 才能由实机桥接发送速度数字；旧脉冲固件会把数字当作原始 PWM 命令。兼容的 `bench.py` 也识别历史 V1 固件。新 `S2` 状态行包含 ESP 单调微秒、两轮计数与跳变数、速度、目标、PWM、运动位和故障码；旧 `S` 行暂保留给已有诊断脚本。

- `v 60 60\n`：左右轮目标各 +60 mm/s，需要持续刷新，推荐 10 Hz。
- `v -40 -40\n`：左右轮目标各 -40 mm/s。
- `x`：停止，无需换行。
- `c`：仅在停止状态清除故障，不会自动启动。
- `s`：输出状态；默认也每 100 ms 输出状态。
- `r`：兼容只读 `/wheel/odom` 节点的编码器报告。

状态格式：`S uptime_us raw_left raw_right measured_left_mm_s measured_right_mm_s setpoint_left setpoint_right pwm_left pwm_right active fault`。

超出范围、非有限数、格式错误命令均不启动电机；输入行超过 79 字节或组帧超过 200 ms 时停止并丢弃到下一行。不要同时运行串口监视器、轮式里程计节点和测试脚本。

## 构建与有界测试

烧录时先断开驱动板 12 V，仅保留控制器 USB 供电。

```bash
source /home/manbaout/esp/esp-idf/export.sh
idf.py -C firmware/esp32s3_base_control build
idf.py -C firmware/esp32s3_base_control -p /dev/serial/by-id/usb-Espressif_USB_JTAG_serial_debug_unit_90:70:69:F7:F0:B0-if00 flash
```

在项目根目录运行，默认 `inspect` 只验证版本和停止状态。`run` 会发出运动命令，须先确认车轮悬空且可立即断电。

```bash
python3 firmware/esp32s3_base_control/tools/bench.py --action inspect
python3 firmware/esp32s3_base_control/tools/bench.py --action run --left 60 --right 60 --seconds 3 --csv /tmp/base-forward.csv
python3 firmware/esp32s3_base_control/tools/bench.py --action timeout --left 60 --right 60 --seconds 1 --csv /tmp/base-timeout.csv
```

脚本限制持续时间为 0.1–10 秒，结束后检查 `active=0` 且 PWM=0；`timeout` 模式在运行阶段结束后停止刷新指令，以验证控制器自行超时关闭输出。脚本异常退出时发送 `x`，遥测超过 0.5 秒无响应时中止。CSV 保存本次状态用于调参。新固件版本识别失败时不会发送速度命令。
